3 · Recommendation
01

Prototype for $0, launch for $40/mo

Validate the whole app on the free tier (this page proves it works). Only pay the $39.99/mo GOAT tier when we actually need live play-by-play in production. No enterprise contract needed.

02

One decision drives the cost

How live does play-by-play need to be? Post-game / next-day summaries can stay free. Live in-game, possession-by-possession is the only thing that forces the paid tier.

03

Use BALLDONTLIE, not scraping

It is a clean REST/JSON API, native to a Next.js + Vercel build (same stack as our other projects). Avoid scraping stats.nba.com from the cloud, where datacenter IPs get blocked, the same problem we already hit on the ETF scrapers.

04

Data quality is not a risk

The free feed already returns accurate, structured, complete game data (scores, quarters, leaders, rosters). The build risk is product and design, not data availability.

Bottom line for Ofer

The data is there, it is good, and it is cheap. We can build and demo a full NBA app for $0, and run a live play-by-play version in production for ~$40/month. Nothing about the data blocks us from starting.

Data source & honesty note: the game data on this page was pulled live from a free public NBA data feed (ESPN's open endpoint), which returns the same class of free-tier data as BALLDONTLIE's free plan. Scores and quarter-by-quarter totals are verified (they sum to the final). The play-by-play block is an illustrative mock of what the paid tier unlocks, and it is intentionally blurred because we do not have that data on the free tier.
